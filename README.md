# shop_2410 — инструкция по локальному запуску

Проект: Django-магазин (Python + Django + SQLite), без Docker.

Ниже два сценария:
1) обычный запуск (есть интернет);
2) запуск на другом ПК без интернета.


## 1. Что нужно для запуска

- Windows 10/11
- Python 3.11.x (рекомендуется 3.11.1+)
- Доступ к PowerShell


## 2. Быстрый запуск (если интернет есть)

Откройте PowerShell в папке проекта и выполните:

1. Создать виртуальное окружение:
python -m venv .venv

2. Активировать окружение:
.\.venv\Scripts\Activate.ps1

3. Установить зависимости:
pip install -r requirements.txt

4. Применить миграции:
python manage.py migrate

5. (Опционально) Создать администратора:
python manage.py createsuperuser

6. Запустить проект:
python manage.py runserver

7. Открыть в браузере:
http://127.0.0.1:8000/


## 3. Подготовка к показу на другом ПК без интернета

Этот раздел делайте заранее на компьютере, где интернет есть.

### 3.1. Подготовить офлайн-зависимости Python

В корне проекта:

1. Активируйте окружение (если еще не активировано):
.\.venv\Scripts\Activate.ps1

2. Скачайте колеса зависимостей в папку offline/wheels:
pip download -r requirements.txt -d offline\wheels

После этого папка offline/wheels будет содержать все нужные пакеты для установки без интернета.

### 3.2. Подготовить офлайн-установщик Python

Скачайте заранее установщик Python 3.11 для Windows (x64) и положите в проект, например:
offline\python-installer\python-3.11.x-amd64.exe

Важно: на целевом ПК Python может отсутствовать, поэтому инсталлятор нужен обязательно.

### 3.3. (Рекомендуется) Подготовить демонстрационные данные

1. Выполните миграции:
python manage.py migrate

2. Создайте администратора:
python manage.py createsuperuser

3. Добавьте категории/товары через админку:
http://127.0.0.1:8000/admin/

4. Если хотите перенести уже заполненную БД, не удаляйте файл db.sqlite3.

### 3.4. Что копировать на флешку

Скопируйте весь проект целиком, включая:
- исходный код
- папку offline/wheels
- requirements.txt
- db.sqlite3 (если есть подготовленные данные)

Можно упаковать в zip, чтобы проще перенести.


## 4. Запуск на ПК в вузе без интернета

### 4.1. Установить Python (если не установлен)

Запустите офлайн-инсталлятор из папки offline/python-installer.

При установке отметьте:
- Add Python to PATH

### 4.2. Развернуть проект

1. Распакуйте проект, например в:
C:\projects\shop_2410

2. Откройте PowerShell в этой папке.

3. Создайте venv:
python -m venv .venv

4. Активируйте venv:
.\.venv\Scripts\Activate.ps1

5. Установите зависимости строго из локальной папки (без интернета):
pip install --no-index --find-links=offline\wheels -r requirements.txt

6. Примените миграции (если БД пустая):
python manage.py migrate

7. Запустите сервер:
python manage.py runserver

8. Откройте:
http://127.0.0.1:8000/


## 5. Вход в админку

Админка доступна по адресу:
http://127.0.0.1:8000/admin/

Если суперпользователь еще не создан:
python manage.py createsuperuser


## 6. Важный комментарий про интерфейс без интернета

В проекте подключены внешние CDN-ресурсы (Bootstrap, htmx, Google Fonts).

Это влияет только на внешний вид и часть динамики интерфейса.
Базовая серверная логика Django (регистрация, каталог, корзина, заказы, роли, админка) продолжит работать и без интернета.

Если нужен полностью автономный UI без CDN, можно заранее локализовать эти ресурсы в папку assets и подключать их как локальные static-файлы.


## 7. Типовые проблемы и решения

1. Ошибка активации скриптов PowerShell:
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

2. Python не найден:
Переустановите Python и включите Add Python to PATH.

3. Порт 8000 занят:
python manage.py runserver 127.0.0.1:8001

4. Ошибки БД при переносе:
- удалите db.sqlite3 (если переносите без данных)
- заново выполните: python manage.py migrate


## 8. Команды для быстрой проверки перед показом

1. Проверка проекта:
python manage.py check

2. Проверка миграций:
python manage.py showmigrations

3. Запуск:
python manage.py runserver


## 9. Запуск с флешки за 3 минуты

Если вы принесли именно эту папку проекта на флешке, делайте так:

1. Скопируйте папку проекта с флешки на локальный диск, например:
C:\projects\shop_2410

2. Откройте PowerShell в папке проекта.

3. Создайте новое виртуальное окружение:
python -m venv .venv

4. Активируйте окружение:
.\.venv\Scripts\Activate.ps1

5. Установите зависимости:
- с интернетом:
pip install -r requirements.txt
- без интернета (из заранее подготовленной папки):
pip install --no-index --find-links=offline\wheels -r requirements.txt

6. Подготовьте БД:
- если переносите готовый db.sqlite3, этот шаг можно пропустить;
- если БД новая или пустая:
python manage.py migrate

7. Запустите сервер:
python manage.py runserver

8. Откройте сайт:
http://127.0.0.1:8000/

Важно:
- не переносите старую папку .venv между ПК;
- .venv всегда создавайте заново на новом компьютере.
